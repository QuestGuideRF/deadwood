# Deadwood

Браузерная 2D-игра на HTML5 Canvas о сборе валежника. Проживи как можно дольше, собирая ресурсы, пока растут налоги и цены на еду.

## ✨ Особенности

- Геймплей в реальном времени на HTML5 Canvas
- Система сбора ресурсов и экономики
- AI-боты конкуренты с поиском ресурсов
- Динамическая генерация карты
- Параллакс-фон для эффекта глубины
- Анимация персонажей

## 🚀 Быстрый старт

### Установка

```bash
npm install
```

### Запуск в режиме разработки

```bash
gulp
```

Откроется браузер с игрой по адресу `http://localhost:3000`

### Сборка для продакшена

```bash
gulp build
```

Собранные файлы будут в папке `dist/`

## 📁 Структура проекта

```
deadwood/
├── app/
│   ├── index.html         # Главная страница
│   ├── css/               # Скомпилированные стили
│   ├── js/
│   │   ├── deadwood.class.js  # Игровые классы (Entity, Player, Rival и др.)
│   │   └── common.js          # Основная игровая логика
│   ├── img/               # Графические ресурсы
│   ├── fonts/             # Шрифты
│   ├── libs/              # Внешние библиотеки
│   └── sass/              # SASS исходники
├── gulpfile.js            # Конфигурация сборки
└── package.json           # Зависимости проекта
```

## 🛠 Управление

| Клавиша | Действие |
|---------|----------|
| `A` | Движение влево |
| `D` | Движение вправо |
| `Shift` | Прыжок |
| `S` | Собрать валежник |

## 🎮 Геймплей

- Собирайте валежник для получения очков
- Следите за уровнем еды — он постоянно уменьшается
- Покупайте еду в магазине за собранные ресурсы
- Цены растут со временем
- Боты-конкуренты также собирают валежник

## 🧪 Технологии

- **HTML5 Canvas** — игровой движок
- **JavaScript ES6** — игровая логика и классы
- **SASS** — препроцессор стилей
- **Gulp** — сборка и автоматизация
- **Browser-Sync** — live-reload при разработке
